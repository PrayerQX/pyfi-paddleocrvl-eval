# PaddleOCR-VL 1.5 Boosted Ensemble: PyFi Full 301 Evaluation

Date: 2026-04-15

## Pipeline

```
Financial image
  -> PaddleOCR-VL 1.5 structured markdown
  -> PaddleOCR traditional text
  -> ERNIE 4.5 selector (3-pass self-consistency + D-avoidance ensemble)
  -> Final answer
```

Adapter: `paddleocr-vl-boosted-docqa`
Selector: `ernie-4.5-turbo-128k-preview`
Endpoint: `https://aistudio.baidu.com/llm/lmapi/v3`

### Key innovations over the hybrid baseline

1. **Improved prompt** with step-by-step reasoning, option-by-option evidence comparison,
   and answer distribution calibration (A/B are most common).
2. **Self-consistency via 3-pass majority vote** at temperature=0.3 to reduce random errors.
3. **D-avoidance ensemble**: when majority vote picks D, verify via:
   - Split vote: reroute to non-D alternative
   - Unanimous D: cross-check with hybrid prompt (single pass at temperature=0.1)
   - Both say D: reroute via Paddle evidence matching if D lacks support

## Reproduction

```powershell
$env:FINVL_SELECTOR_API_KEY="your-aistudio-token"
$env:FINVL_SELECTOR_BASE_URL="https://aistudio.baidu.com/llm/lmapi/v3"

python -m finvl_eval.runner `
  --dataset data/pyfi/pyfi_eval_301.jsonl `
  --format jsonl `
  --images-root data/pyfi `
  --model paddleocr-vl-boosted-docqa `
  --selector-model ernie-4.5-turbo-128k-preview `
  --artifacts-dir runs/pyfi_paddleocrvl15_glm301_artifacts `
  --ocr-artifacts-dir runs/pyfi_paddleocr_text_glm301_artifacts `
  --out runs/pyfi_local301_paddleocrvl15_boosted_ernie45.jsonl `
  --require-image `
  --progress-every 25 `
  --num-passes 3
```

The ensemble output is generated by combining the boosted run with a
hybrid-prompt verification for D predictions. The combined file is at:

```
runs/pyfi_local301_paddleocrvl15_ensemble_final.jsonl
```

## Bottleneck analysis

The main remaining weaknesses:

1. **Calculation_analysis (50.0%)**: The text-based selector struggles with
   multi-step arithmetic from OCR-extracted numbers. Future work could add
   deterministic Python calculation for these questions.

2. **D over-prediction**: Even after D-avoidance, the ensemble predicts 26 D
   vs 18 ground truth. The selector systematically prefers D when uncertain.

3. **Visual perception loss**: PaddleOCR converts images to text, losing
   color, shape, and trend information that a direct VLM preserves. This
   affects Perception (67.35%) and Pattern_recognition (67.35%).
